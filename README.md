The projects in this repository are being generated using the [quarkus CLI](https://quarkus.io/guides/cli-tooling/).

Add extra extensions:

```sh
quarkus ext add [name-of-extension]
```

Available extensions can be found [here](https://quarkus.io/extensions/).

- `smartmeter-service`: rest-jaxb, rest-jackson, websockets-next
